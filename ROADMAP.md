# Roadmap

The full path. 23 sections plus a foundation section. The spine is the **LeetCode Top Interview 150**
(150 problems). Each section also lists **extra reps** from NeetCode 150 and Codility Lessons for when you
want more practice before the gate.

Difficulty: E = Easy, M = Medium, H = Hard. Numbers are LeetCode problem numbers.

---

## Why this order

It follows the Top Interview 150 order, with one change: **Section 00 comes first** so the Python itself
never gets in the way of the thinking. Later sections lean on earlier ones. Two Pointers reuses Array/String
skills. Trees need recursion, which Linked List starts. Graphs reuse tree traversal. DP reuses recursion and
arrays. Don't skip ahead unless you pass that section's diagnostic.
