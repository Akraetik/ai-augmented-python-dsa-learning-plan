# 01-5 Array and String Rapid Fire Drill

**Narrator:** Section one, track five. Rapid fire drill. Arrays and strings.

**Narrator:** In place, return k, first k elements. Pattern?

*[pause 3s]*

**Answer:** Read and write pointers.

**Narrator:** The three steps of read and write?

*[pause 5s]*

**Answer:** Write starts at zero. Copy keepers to write and move it. Return write.

**Narrator:** Remove Duplicates keep rule?

*[pause 4s]*

**Answer:** Write is zero, or different from write minus one.

**Narrator:** Remove Duplicates two keep rule?

*[pause 4s]*

**Answer:** Write under two, or different from write minus two.

**Narrator:** Merge Sorted Array fills from which end?
