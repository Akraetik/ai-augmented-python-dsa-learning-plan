# 3.4 · Windows Made of Words

**Lab:** 08 Substring with Concatenation of All Words (Stretch)
**Time:** 45 minutes, then the lab. Do it last.

---

## The problem

`words` is a list of words that all have the **same length**. Find every index in `s` where some
ordering of **all** the words appears back to back, with nothing in between.

```
s = "barfoothefoobarman", words = ["foo", "bar"]
     bar|foo                     → index 0 works ("barfoo")
              foo|bar            → index 9 works ("foobar")
answer: [0, 9]
```

## Think in words, not letters

Every word is length `L`. So chop `s` into `L`-sized pieces and treat each piece as one item.

```
s = "barfoothefoobarman", L = 3
pieces from 0:  bar | foo | the | foo | bar | man
```

Now it's a **fixed-size window of words**, like Permutation in String (lesson 3.1), but over pieces:
window size = `len(words)`, and the window is good when its word counts equal `Counter(words)`.

## The catch: where do the pieces start?

A match could start at index 0, 1, or 2 (for `L = 3`). Chopping from 0 only finds matches at
0, 3, 6, 9... A match at index 1 lines up with a different chopping.

So run the window **`L` times**: once starting at offset 0, once at 1, ..., once at `L − 1`.
Each run steps by `L`. Together they cover every possible start.

```
offset 0:  bar|foo|the|foo|bar|man
offset 1:  arf|oot|hef|oob|arm
offset 2:  rfo|oth|efo|oba|rma
```

## Inside one run

Use the **variable-window** shrink idea from lesson 3.2:

1. Take the next piece `w`.
2. If `w` isn't one of the words at all → the window can't contain it. Clear the window and start fresh after it.
3. Otherwise add `w` to the window's counts. While `w` now appears **more times than `words` has it**,
   drop pieces from the left.
4. If the window holds exactly `len(words)` pieces, record its start. Then drop the leftmost piece to keep sliding.

Cost: `L` runs × about `len(s) / L` pieces each = **O(len(s))** piece steps, each costing O(L) to slice. Fine.

## The brute force, for comparison

For every start index, slice `len(words)` pieces and compare counts. That's
O(len(s) × len(words) × L). With `s` of 10,000 letters and 5,000 one-letter words, that's tens of millions of
steps in Python. The lab's speed test is built to catch it.

## Pattern trigger

> **"All words, same length, concatenated in any order" → slide a window of word-sized pieces, once per offset 0..L−1.**
