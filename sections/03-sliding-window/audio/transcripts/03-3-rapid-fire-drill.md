# 03-3 Sliding Window Rapid Fire Drill

**Narrator:** Section three, track three. Rapid fire. Say it before you hear it. Repeat this track until it's easy.

*[pause 2s]*

**Narrator:** What is a window?

*[pause 3s]*

**Answer:** A run of items next to each other.

**Narrator:** Every window of size k. Template?

*[pause 3s]*

**Answer:** Fixed window.

**Narrator:** Fixed window slide. What changes?

*[pause 3s]*

**Answer:** One enters, one leaves.

**Narrator:** When nums at right enters, which index leaves?

*[pause 3s]*

**Answer:** Right minus k.

**Narrator:** Fixed window Big O?

*[pause 3s]*

**Answer:** O of n.

**Narrator:** Rearrangement of a string. Compare what?

*[pause 3s]*

**Answer:** Letter counts.

**Narrator:** Longest run that follows a rule. Template?

*[pause 3s]*

**Answer:** Longest valid window.

**Narrator:** Longest valid. Shrink when?

*[pause 3s]*

**Answer:** While broken.

**Narrator:** Longest valid. Record where?

*[pause 3s]*

**Answer:** After the while.

**Narrator:** Longest valid. Best starts at?

*[pause 3s]*

**Answer:** Zero.

**Narrator:** Shortest run that meets a goal. Template?

*[pause 3s]*

**Answer:** Shortest valid window.

**Narrator:** Shortest valid. While loop runs when?

*[pause 3s]*

**Answer:** While valid.

**Narrator:** Shortest valid. Record where?

*[pause 3s]*

**Answer:** Inside the while, before shrinking.

**Narrator:** Shortest valid. Best starts at?

*[pause 3s]*

**Answer:** Infinity.

**Narrator:** Window length?

*[pause 3s]*

**Answer:** Right minus left plus one.

**Narrator:** Shrink with if or while?

*[pause 3s]*

**Answer:** While.

**Narrator:** Why is a while inside a for still O of n?

*[pause 4s]*

**Answer:** Left only moves forward. At most n moves.

**Narrator:** Longest substring without repeats. Broken when?

*[pause 3s]*

**Answer:** A letter appears twice.

**Narrator:** Jump version. Why max of left?

*[pause 4s]*

**Answer:** So left never moves backward.

**Narrator:** Flip up to k zeros. Window rule?

*[pause 3s]*

**Answer:** At most k zeros inside.

**Narrator:** Character replacement. Changes needed?

*[pause 4s]*

**Answer:** Length minus the most common count.

**Narrator:** Minimum size subarray sum. Nothing works. Return?

*[pause 3s]*

**Answer:** Zero.

**Narrator:** Sliding window with negative numbers in a sum?

*[pause 3s]*

**Answer:** No. Use prefix sums.

**Narrator:** Minimum window substring. Have goes up when?

*[pause 4s]*

**Answer:** A letter's count reaches what t needs.

**Narrator:** Minimum window substring. Record what?

*[pause 3s]*

**Answer:** Start and length.

**Narrator:** Concatenation of all words. Runs per word length L?

*[pause 3s]*

**Answer:** L. One per offset.

**Narrator:** A word piece that isn't in the list?

*[pause 3s]*

**Answer:** Clear the window and restart after it.

**Narrator:** Pair from anywhere in a sorted list. Window or two pointers?

*[pause 3s]*

**Answer:** Two pointers from the ends.

**Narrator:** New bug in this section?

*[pause 3s]*

**Answer:** Shrinking with if instead of while.

*[pause 1s]*

**Narrator:** End of drill.
