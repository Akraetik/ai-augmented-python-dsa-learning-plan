## The problem

A 9 × 9 board is partly filled with digits `"1"`–`"9"` and `"."` for empty. It's **valid** if no digit repeats in:

- any row,
- any column,
- any of the nine 3 × 3 boxes.

You don't solve the puzzle. You only check what's already there.

## Three groups of sets

"Have I seen this digit in this row before?" is the Section 00 question: **use a set.**
You need one set per row, one per column, and one per box. That's 27 sets.

```python
rows = [set() for _ in range(9)]
cols = [set() for _ in range(9)]
boxes = [set() for _ in range(9)]
```

Walk every cell once. For a digit `d` at `(r, c)`: if `d` is already in its row set, column set, or box set,
the board is invalid. Otherwise add it to all three.

## Which box is a cell in?

Number the boxes 0 to 8, left to right, top to bottom:

```
 box 0 | box 1 | box 2        rows 0-2
-------+-------+-------
 box 3 | box 4 | box 5        rows 3-5
-------+-------+-------
 box 6 | box 7 | box 8        rows 6-8
```

`r // 3` gives the box **row** (0, 1, or 2). `c // 3` gives the box **column**. So:

```python
box = (r // 3) * 3 + (c // 3)
```

Cell `(4, 7)`: `4 // 3 = 1`, `7 // 3 = 2` → box `1 * 3 + 2 = 5`. Check it on the picture.

This "flatten two numbers into one index" move comes back often. `row * width + col` turns a grid position
into a single number. Here the "grid" is the 3 × 3 grid of boxes.

Another option: key one dictionary of sets by the tuple `(r // 3, c // 3)`. Same idea, no arithmetic.

## Cost

The board is always 9 × 9. That's 81 cells, a constant. Interviewers still want to hear the general answer:
for an `n × n` board, one pass with set lookups is **O(n²)**, the number of cells.

## Common mistakes

- Treating `"."` as a digit. Skip it.
- Using `r // 3 + c // 3` (that's 0–4, not 0–8; boxes collide).
- Returning `True` after the first good cell. (Mistake **M7**: "valid" can only be decided after the whole board.)

## Pattern trigger

> **"No repeats within each row / column / block" → one set per group; block index `(r // k) * (n // k) + (c // k)`.**
