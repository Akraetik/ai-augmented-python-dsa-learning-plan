# 04-3 Matrix Rapid Fire Drill

**Narrator:** Section four, track three. Rapid fire. Say it before you hear it. Repeat this track until it's easy.

*[pause 2s]*

**Narrator:** Row first, or column first?

*[pause 3s]*

**Answer:** Row first.

**Narrator:** Number of rows?

*[pause 3s]*

**Answer:** Length of the grid.

**Narrator:** Number of columns?

*[pause 3s]*

**Answer:** Length of the first row.

**Narrator:** Big O of visiting every cell?

*[pause 3s]*

**Answer:** O of m times n.

**Narrator:** Safe way to build an empty grid?

*[pause 3s]*

**Answer:** A comprehension, one new row each time.

**Narrator:** Neighbor check comes before or after the read?

*[pause 3s]*

**Answer:** Before.

**Narrator:** How many neighbors with diagonals?

*[pause 3s]*

**Answer:** Eight.

**Narrator:** Transpose. Row r, column c goes where?

*[pause 3s]*

**Answer:** Row c, column r.

**Narrator:** Main diagonal?

*[pause 3s]*

**Answer:** Row equals column.

**Narrator:** Anti-diagonal?

*[pause 3s]*

**Answer:** Row plus column equals n minus one.

**Narrator:** Odd n, both diagonals. Watch for?

*[pause 3s]*

**Answer:** The center counts once.

**Narrator:** No repeats in each row, column, and box. Tool?

*[pause 3s]*

**Answer:** One set per group.

**Narrator:** Sudoku box formula?

*[pause 4s]*

**Answer:** Row over three, times three, plus column over three.

**Narrator:** Rotate clockwise in place?

*[pause 3s]*

**Answer:** Transpose, then reverse each row.

**Narrator:** In-place transpose swaps which cells?

*[pause 3s]*

**Answer:** Column bigger than row.

**Narrator:** Rotate counterclockwise?

*[pause 3s]*

**Answer:** Transpose, then reverse the row order.

**Narrator:** Spiral. How many walls?

*[pause 3s]*

**Answer:** Four.

**Narrator:** Spiral. Which steps re-check?

*[pause 3s]*

**Answer:** Bottom row and left column.

**Narrator:** Spiral. Two test cases to run first?

*[pause 3s]*

**Answer:** One row, and one column.

**Narrator:** Turning walker. Turn right how?

*[pause 3s]*

**Answer:** d plus one, mod four.

**Narrator:** Set Matrix Zeroes. First rule?

*[pause 3s]*

**Answer:** Record first, write second.

**Narrator:** O of one flags live where?

*[pause 3s]*

**Answer:** Row zero and column zero.

**Narrator:** Which do you zero last?

*[pause 3s]*

**Answer:** Row zero and column zero.

**Narrator:** Game of Life. Two means?

*[pause 3s]*

**Answer:** Live to dead.

**Narrator:** Three means?

*[pause 3s]*

**Answer:** Dead to live.

**Narrator:** Live with two or three neighbors?

*[pause 3s]*

**Answer:** Lives.

**Narrator:** Dead with exactly three?

*[pause 3s]*

**Answer:** Becomes live.

**Narrator:** New bug in this section?

*[pause 3s]*

**Answer:** A missing re-check after the walls move.

*[pause 1s]*

**Narrator:** End of drill.
