## Lists

A list holds items in order. Each item has a **position**, called an **index**. Indexes start at 0.

```python
nums = [7, 3, 9, 4]
#  index: 0  1  2  3
```

```python
nums[0]      # 7      first
nums[3]      # 4      last
nums[-1]     # 4      last, counting from the end
nums[-2]     # 9      second to last
len(nums)    # 4
nums[4]      # IndexError: there is no index 4
```

The last valid index is always `len(nums) - 1`. Off-by-one bugs live here. (Mistake **M5**.)

### Index vs value

This is the most common beginner bug. Burn it in.

- **Index** = the position. `0, 1, 2, 3`.
- **Value** = the thing at that position. `7, 3, 9, 4`.

```python
for x in nums:            # x is a VALUE: 7, 3, 9, 4
    print(x)

for i in range(len(nums)):    # i is an INDEX: 0, 1, 2, 3
    print(i, nums[i])

for i, x in enumerate(nums):  # both at once
    print(i, x)
```

`nums[x]` when `x` is a value is almost always a bug. (Mistake **M1**.)
If you need both, use `enumerate`.

### Changing a list

```python
nums = [7, 3, 9]
nums.append(5)       # [7, 3, 9, 5]   add to end, O(1)
nums.pop()           # returns 5, list is [7, 3, 9]   O(1)
nums[1] = 100        # [7, 100, 9]   replace by index, O(1)
nums.pop(0)          # returns 7. O(n). Avoid in loops.
nums.insert(0, 1)    # O(n). Avoid in loops.
```

### Swapping

```python
a, b = b, a                       # swap two variables
nums[i], nums[j] = nums[j], nums[i]   # swap two list items
```

You'll use the second line hundreds of times in this course.

### Slicing

`nums[start:stop]` gives a **new list** from `start` up to but **not including** `stop`.

```python
nums = [10, 20, 30, 40, 50]
nums[1:3]    # [20, 30]
nums[:2]     # [10, 20]       start defaults to 0
nums[2:]     # [30, 40, 50]   stop defaults to the end
nums[::-1]   # [50, 40, 30, 20, 10]   reversed copy
nums[:]      # a full copy
```

Slices **copy**. Copying costs O(k) for k items. Fine once. Bad inside a loop.

### Making lists

```python
[0] * 5            # [0, 0, 0, 0, 0]
list(range(5))     # [0, 1, 2, 3, 4]
[x * 2 for x in nums]    # list comprehension, covered in Part 2
```

### Lists of lists: the trap

```python
grid = [[0] * 3] * 3       # WRONG: three references to ONE row
grid[0][0] = 1             # changes every row!

grid = [[0] * 3 for _ in range(3)]   # RIGHT: three separate rows
```

You'll need this in the Matrix section.

## Strings

A string is a sequence of characters. It works like a list for reading.

```python
s = "hello"
s[0]        # 'h'
s[-1]       # 'o'
len(s)      # 5
s[1:4]      # 'ell'
s[::-1]     # 'olleh'
for ch in s:
    print(ch)
```

**Strings are immutable.** You can't change one in place.

```python
s[0] = "H"         # TypeError
s = "H" + s[1:]    # makes a NEW string. Fine.
```

### Building a string: use a list

Adding strings in a loop makes a new string every time. Collect pieces in a list. Join once at the end.

```python
# slow pattern
out = ""
for ch in s:
    out += ch.upper()

# fast pattern
parts = []
for ch in s:
    parts.append(ch.upper())
out = "".join(parts)
```

`"".join(parts)` glues the pieces with nothing between them. `" ".join(words)` glues with spaces.

### String tools you'll use constantly

```python
"  hi there ".strip()      # 'hi there'     trims both ends
"a b  c".split()           # ['a', 'b', 'c']  splits on any whitespace, drops empties
"a,b,c".split(",")         # ['a', 'b', 'c']
"Hello".lower()            # 'hello'
"hello".upper()            # 'HELLO'
"a1".isalnum()             # True: letters or digits only
"7".isdigit()              # True
"x".isalpha()              # True
"abc".startswith("ab")     # True
"hello".find("ll")         # 2  (-1 if not found)
"banana".count("a")        # 3
```

### Characters as numbers

Every character has a number. `ord` turns a character into its number. `chr` turns it back.

```python
ord("a")          # 97
ord("b")          # 98
chr(97)           # 'a'
ord("c") - ord("a")   # 2  -> "c" is letter number 2 (counting from 0)
```

That last line lets you map letters to indexes 0–25. You'll use it for counting letters fast.

## Loops

### `for` loops

Use `for` when you know what you're walking through.

```python
for x in nums: ...                 # every value
for i in range(len(nums)): ...     # every index
for i in range(1, len(nums)): ...  # every index except 0
for i in range(len(nums) - 1, -1, -1): ...  # indexes, backward
for x in reversed(nums): ...       # values, backward
for a, b in zip(list1, list2): ... # pairs, stops at the shorter one
```

`range(start, stop, step)` goes up to but **not including** `stop`. Same rule as slicing.

### `while` loops

Use `while` when you move by your own rules. Two pointers use this.

```python
left, right = 0, len(nums) - 1
while left < right:
    # do something
    left += 1          # don't forget to move! (Mistake M4)
    right -= 1
```

If you forget to change `left` or `right`, the loop runs forever.
`left + 1` on its own line does **nothing**. `left += 1` saves it. (Mistake **M4**.)

### `break` and `continue`

```python
for x in nums:
    if x < 0:
        continue    # skip to the next x
    if x > 100:
        break       # leave the loop now
    print(x)
```

### Returning from inside a loop

```python
def all_positive(nums):
    for x in nums:
        if x <= 0:
            return False    # one bad item is enough to say False
    return True             # only after checking ALL of them
```

"False" answers can return early. "True" answers usually wait until after the loop. (Mistake **M7**.)

## Functions

```python
def area(width, height):
    return width * height

def greet(name="friend"):     # default value
    return f"Hi, {name}"      # f-string: {} drops a value into the text
```

A function can return several things as a tuple:

```python
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([4, 1, 9])   # lo = 1, hi = 9
```

Functions can change a list you pass in. They can't make the caller's variable point to a new list.

```python
def add_one(nums):
    nums.append(1)     # caller sees this
    nums = [99]        # caller does NOT see this. It just renames locally.
```

That's why in-place problems say "modify `nums`" and you write `nums[i] = ...`, not `nums = ...`.
