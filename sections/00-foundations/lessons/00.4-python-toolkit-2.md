## Why these matter

Lists are slow at one thing: **finding.** `x in my_list` checks every item.
Dicts and sets find things in **O(1)**. They turn many O(n²) problems into O(n).
If you remember one sentence from this lesson, make it this one:

> **When you need to ask "have I seen this before?" — use a set or a dict.**

## Sets

A set holds unique items. No order. No duplicates. Fast membership.

```python
seen = set()           # empty set. NOT {} — that's an empty dict.
seen.add(3)
seen.add(3)            # still just {3}
3 in seen              # True, O(1)
seen.remove(3)         # error if missing
seen.discard(3)        # no error if missing
len(seen)

s = set([1, 2, 2, 3])  # {1, 2, 3}
a & b    # in both
a | b    # in either
a - b    # in a, not b
```

**Pattern: "seen before?"**

```python
def has_duplicate(nums):
    seen = set()
    for x in nums:
        if x in seen:
            return True
        seen.add(x)
    return False
```

O(n) time, O(n) space. The nested-loop version is O(n²).

## Dicts

A dict maps **keys** to **values**. Lookup by key is O(1).

```python
ages = {"ana": 31, "bo": 25}
ages["ana"]               # 31
ages["cy"] = 40           # add or overwrite
"bo" in ages              # True: checks KEYS
ages.get("zed")           # None, no error
ages.get("zed", 0)        # 0, a default
del ages["bo"]

for key in ages: ...               # keys
for key, val in ages.items(): ...  # both
ages.keys(), ages.values()
```

Keys must be **immutable**: numbers, strings, tuples. Not lists.

### Pattern: counting

```python
counts = {}
for ch in "banana":
    counts[ch] = counts.get(ch, 0) + 1
# {'b': 1, 'a': 3, 'n': 2}
```

### Pattern: remember where you saw it

```python
index_of = {}
for i, x in enumerate(nums):
    index_of[x] = i      # value -> its index
```

This is how Two Sum goes from O(n²) to O(n).

## `collections`: the power tools

```python
from collections import Counter, defaultdict, deque
```

### Counter — counting in one line

```python
c = Counter("banana")       # Counter({'a': 3, 'n': 2, 'b': 1})
c["a"]                      # 3
c["z"]                      # 0, no error
c.most_common(1)            # [('a', 3)]
Counter("listen") == Counter("silent")   # True: an anagram check
```

**Trigger:** the problem says "frequency," "count," "how many times," or "anagram."

### defaultdict — a dict with an automatic default

```python
groups = defaultdict(list)
groups["fruit"].append("apple")   # no KeyError; starts as []

counts = defaultdict(int)
counts["x"] += 1                  # starts at 0
```

**Trigger:** grouping things ("group anagrams," "bucket by length").

### deque — fast at both ends

```python
q = deque([1, 2, 3])
q.append(4)         # right end, O(1)
q.appendleft(0)     # left end, O(1)
q.pop()             # right end, O(1)
q.popleft()         # left end, O(1). A list's pop(0) is O(n).
```

**Trigger:** queues and BFS (Section 10 and 13). Anything that removes from the front.

## Sorting

```python
nums.sort()                 # sorts in place, returns None
new = sorted(nums)          # returns a new sorted list
sorted(nums, reverse=True)  # big to small
sorted(words, key=len)      # by length
sorted(pairs, key=lambda p: p[1])        # by the second item of each pair
sorted(pairs, key=lambda p: (p[0], -p[1]))  # first ascending, then second descending
```

Sorting is **O(n log n)**. Often, sorting first makes the rest of the problem easy.
Watch for: `nums = nums.sort()` sets `nums` to `None`. (Mistake **M6** cousin.)

`lambda p: p[1]` is a tiny unnamed function. It means "given p, return p[1]."

## Comprehensions

A short way to build a list, set, or dict.

```python
squares = [x * x for x in range(5)]            # [0, 1, 4, 9, 16]
evens = [x for x in nums if x % 2 == 0]        # filter
unique = {x for x in nums}                     # set
pos = {x: i for i, x in enumerate(nums)}       # dict: value -> index
```

Read them right to left: "for each x in range(5), give me x * x."

## Tuples and unpacking

A tuple is a list you can't change. Use it for fixed groups, like a pair or a grid position.

```python
point = (3, 4)
r, c = point          # unpacking
seen = {(0, 0), (1, 2)}    # tuples can go in a set; lists can't
```

## Numbers

```python
7 // 2        # 3     integer division (rounds down)
7 % 2         # 1     remainder
-7 // 2       # -4    rounds DOWN, not toward zero
divmod(7, 2)  # (3, 1)
abs(-5)       # 5
2 ** 10       # 1024
float("inf")  # bigger than any number: a good starting "best so far" for minimums
float("-inf") # starting value for maximums
```

`x % 2 == 0` means even. `i % n` wraps an index around a list of length `n`. You'll use that in Rotate Array.

Python integers never overflow. Other languages make you worry about this. Python doesn't.

## Choosing the right tool

| You need to... | Use | Lookup cost |
|---|---|---|
| keep items in order, access by position | `list` | index O(1), search O(n) |
| ask "have I seen this?" | `set` | O(1) |
| map a thing to a count or position | `dict` / `Counter` | O(1) |
| group things | `defaultdict(list)` | O(1) |
| take from the front repeatedly | `deque` | O(1) at ends |
| always get the smallest item | `heapq` (Section 19) | O(log n) |

## Trace it

```python
from collections import Counter
c = Counter([3, 1, 3, 2, 3, 1])
print(c.most_common(2))
```

```python
d = {}
for i, w in enumerate(["a", "b", "a"]):
    d[w] = i
print(d)
```

```python
print(sorted(["pear", "fig", "apple"], key=len))
```

<details><summary>Answers</summary>

- `[(3, 3), (1, 2)]` — value 3 appears 3 times, value 1 twice.
- `{'a': 2, 'b': 1}` — the second `"a"` overwrites the first.
- `['fig', 'pear', 'apple']` — lengths 3, 4, 5.
</details>
